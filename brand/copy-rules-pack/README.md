# Copy Rules Pack

Our copywriting rules, quality gates, skills, and reference library, set up for Claude Code.

## Setup (2 minutes)

**Option A: use it as its own project.** Open this folder in Claude Code (`cd copy-rules-pack && claude`). Claude reads `CLAUDE.md` automatically and knows which file to load for each type of copy.

**Option B: add it to an existing project.** Copy everything in this folder into your project root. If you already have a `CLAUDE.md`, paste the contents of this pack's `CLAUDE.md` onto the end of yours.

Then just ask normally: "write 5 ad hooks for X", "write a VSL for Y", "edit this sales page".

## What's inside

- `Context/Marketing/copy-rules.md`: **start here.** The hard rules (banned words, no em dashes, no AI cadence).
- `Skills/Marketing/OUTPUT-QUALITY-GATES.md` + `Skills/quality-check-output/`: pre-ship checks.
- `Skills/Marketing/Copy/`: copywriting skills (direct response, VSL, angles, brand voice, editing, humanizer), modules per asset type, templates, and deep references.
- `Context/Marketing/Copy/`: copywriting SOP, mega copy docs, hooks and headlines swipe file.
- `Context/Marketing/Ads/`: ad-writing canon (Haynes), ad scripting guides, Meta ad policy pre-flight.
- `Context/Marketing/Funnels/`: VSL, webinar pitch/close, and application form copy.
- `Context/Marketing/Email/`: email matrix.
- `References/`: positioning, philosophy, and offer/pricing/hook frameworks.

For the best output, give Claude your business context: offer, audience, proof, voice. `Skills/Marketing/Copy/templates/copy-foundation.md` is the intake template.
