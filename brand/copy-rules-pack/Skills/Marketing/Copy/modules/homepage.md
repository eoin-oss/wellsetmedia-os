# Homepage Module

> Activates when `homepage` is listed in knowledge.md `modules_active`, or the deliverable is a website
> homepage (not a single-offer sales page).

## What This Module Adds

The core SKILL.md covers the universal frameworks; `sales-pages.md` covers the single-offer long-form
page. This module adds the **homepage**, which is a different animal: a sales page sells ONE thing to ONE
ready buyer; a homepage orients MANY visitors at different awareness levels and routes them to the right
next step. It's navigational, brand-led, and shorter. Fills the gap where the system previously only had
sales pages. (Sourced from the AI Ads Mastery LP/homepage guidance, reconciled with our standards.)

## The Homepage Backbone

1. **Above the fold (the 5-second test):**
   - **Value-prop headline** = *what you do + who it's for + the outcome*. Not clever — clear. "We install AI marketing departments for service businesses so you stop drowning in fulfillment."
   - **Subhead** — expand the main benefit / name the mechanism in one line.
   - **Primary CTA** — one dominant action, above the fold.
   - **Hero proof** — a logo strip, a number, or one strong line of social proof in view immediately.
2. **Quick wins (3–4):** the top benefits as scannable cards — each an outcome, not a feature.
3. **Social-proof band:** high-profile logos / a testimonial / a usage stat. Place near the first CTA.
4. **How it works (3 steps):** reduce perceived effort. "Book → we build → you run it."
5. **Differentiator / enemy:** one section naming the old way you replace (copy-rules #6).
6. **Secondary CTA + clear navigation:** for not-yet-ready visitors — a path to learn more (not a dead end).

## Homepage vs Sales Page (don't confuse them)
| | Homepage | Sales page |
|---|---|---|
| Audience | Many awareness levels | One ready buyer |
| Goal | Orient + route | Close one offer |
| Length | Short, scannable | Long, complete |
| CTAs | Primary + secondary paths | Repeated single CTA |
| Voice | Brand-led | Offer-led |

## Framework fit
Use **Hero/Benefits/CTA** or **4 Ps** (see `Skills/Marketing/Copy/references/framework-catalog.md`). PAS/PASTOR are for sales
pages, not homepages.

## Module-Specific Quality Standards
- [ ] Above-the-fold passes the 5-second test (what + who + outcome obvious without scrolling)
- [ ] Value-prop headline is clear before clever; no banned AI phrases (copy-rules)
- [ ] One dominant primary CTA above the fold; secondary path for not-ready visitors (no dead ends)
- [ ] Proof visible in the hero (logo/number/testimonial), not buried
- [ ] Benefits are outcomes, not features ("stop drowning in fulfillment" not "AI workflow engine")
- [ ] Names the enemy / old way it replaces
- [ ] Price anchoring (if shown) follows the value-stack rule: cost-of-inaction, not a total-value table
- [ ] Passes `Skills/Marketing/Copy/references/hostile-validation.md` + voice-check + copy-rules
