# Copywriting Framework Catalog (cheat-sheet)

> The tidy named-formula reference our system lacked. One line each + when to reach for it. For the deep
> psychology behind these (Schwartz awareness/sophistication, Life-Force 8, proof), load
> `Skills/Marketing/Copy/references/persuasion-frameworks-deep-dive.md`. For headline-level formulas, `Skills/Marketing/Copy/references/headline-formulas.md`.

| Framework | Sequence | Best for |
|---|---|---|
| **AIDA** | Attention → Interest → Desire → Action | General long-form, ads, email sequences |
| **PAS** | Problem → Agitate → Solution | Landing pages, email opens, short-form, problem-aware markets |
| **PASTOR** | Problem → Amplify → Story → Transformation → Offer → Response | Long-form sales pages, story-driven |
| **FAB** | Features → Advantages → Benefits | Spec-heavy products; bridge features to payoff |
| **BAB** | Before → After → Bridge | Transformation offers; show the gap, then the bridge across it |
| **4 Ps** | Promise → Picture → Proof → Push | Tight ads, emails, hero sections (Promise the outcome, Picture it, Proof it, Push to act) |
| **4 C's** | Clear · Concise · Compelling · Credible | A quality checklist for ANY copy, not a sequence |
| **QUEST** | Qualify → Understand → Educate → Stimulate → Transition | Educational / high-consideration offers |
| **Hero/Benefits/CTA** | Hero promise → 3-4 benefits → CTA | Landing pages, homepages (classic LP backbone) |
| **Star-Story-Solution** | Relatable hero → their journey → your solution | Founder story, testimonial-as-narrative, About |

## How to choose
- **Problem-aware, cold** → PAS or BAB (lead with the pain/gap).
- **Solution-aware, warm** → AIDA or 4 Ps (lead with the promise).
- **High-ticket / long-form** → PASTOR (story + amplify carry the length).
- **Spec/feature product** → FAB (translate specs to outcomes via the "So What" sweep).
- **Don't force a framework.** It's a skeleton to prevent missing a beat — the `direct-response-copy`
  full sequence (Hook → Problem → Agitate → Mechanism → Proof → Offer → Objections → CTA) already
  contains all of these; pick the named framework when a deliverable needs a tighter, simpler shape.
