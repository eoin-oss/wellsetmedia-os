# Copy Rules Pack: Claude Code Instructions

This folder is a copywriting rulebook and reference library. All file paths inside these docs are relative to this folder.

## Always apply (any copy: ads, pages, emails, VSLs, scripts)

1. `Context/Marketing/copy-rules.md`: banned words, banned AI phrases, no em dashes, cadence rules. Non-negotiable.
2. `Skills/Marketing/Copy/quality-bar.md`: the bar a piece must clear before it ships.
3. `Skills/Marketing/OUTPUT-QUALITY-GATES.md`: run these checks before handing anything over.
4. Never invent proof, metrics, testimonials, guarantees, or client facts. If it isn't supplied, leave a `[PLACEHOLDER]`.

## Notes

- Some docs mention paths that aren't in this pack (`Clients/{slug}`, `MyBusiness`, `Skills/voice-check`, `Skills/conventions/workspace.md`, validation scripts). Those belong to the original system. Swap in your own business or client context wherever they appear, and skip any script-based check that isn't present here.
- Before writing for a business, collect its offer, audience, proof, and voice. `Skills/Marketing/Copy/templates/copy-foundation.md` is the intake template.
