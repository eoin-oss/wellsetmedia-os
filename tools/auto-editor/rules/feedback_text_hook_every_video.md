Every video that ships (client or own, any format) gets a text hook. Rules live in
`$WSM_HOME/sops/reference/text-hooks.md`: subject + dream outcome / teaser / state change, specific numbers, niche
words, two lines broken on the phrase, no filler words, no punctuation except ( ) and " ", all caps, adds a charge
rather than repeating the spoken hook.

**Why:** Eoin, 21 Oct 2026: he hadn't been putting a text hook on every video; built from a Kallaway breakdown.
**How to apply:** any edit build (auto-edit, podcast clips, seminar shorts) isn't done until each video has one;
draft them, show the list, then build. Related: [[feedback_kyle_no_swearing]], [[project_ai_editor_modes]].
