**UPDATE 2026-10-16: Eoin now runs DaVinci Resolve STUDIO 21.1.1** (bought license) so external scripting via `DaVinciResolveScript` should work directly (needs Preferences > System > General > External scripting = Local); prefer direct Python API over the Lua menu-click route below once verified. Test script pattern: append `/Library/Application Support/Blackmagic Design/DaVinci Resolve/Developer/Scripting/Modules` to sys.path, `dvr.scriptapp("Resolve")`. Historical: on **free 20.2.1** external scripting (`DaVinciResolveScript`, `fuscript`) returned nil. The route that works: write a **Lua** script into `~/Library/Application Support/Blackmagic Design/DaVinci Resolve/Fusion/Scripts/Utility/`, then fire it with AppleScript/System Events (`click menu item "<name>" of menu 1 of menu item "Scripts" of menu 1 of menu bar item "Workspace"` on process `Resolve`). Works with Resolve fullscreen and in the background; have the Lua write a log file to verify. `fuscript -l lua <file>` is a free syntax check.

**Asset library = `/Volumes/Extreme SSD/editiing assets`** (his call, 2026-10-01 — not the 10GB `~/Desktop/WellSetMedia/Basic Video Editing Assets 3` copy). He needs assets as a **Power Bin** (all projects), not a project bin — a project-level bin is not the deliverable. Done 2026-10-01: Power Bins > Master > `ASSETS` (01 SFX, 02 Music, 03 Overlays; 570 clips). His older Power Bins `assets`, `Bin 1`, `MotionText Pro` were left untouched.

Power Bins are not reachable from the API. Working route: generator `$WSM_HOME/tools/resolve_assets_bin.py` writes `Import Editing Assets.lua` → run it from the Scripts menu to build `ASSETS` in the open project → on the Edit page, mouse-drag that bin onto Power Bins > Master (computer use, slow stepped drag) → delete the project copy. The drag **copies**; the Power Bin survives deleting the source.

**Footage imports ("import X from my SSD into the open project"):** `$WSM_HOME/tools/resolve_import_folder.py "<folder>"` — mirrors the folder into bins (top bin = folder name, empty subfolders kept, Sony `.XML` sidecars skipped), fires itself from the Scripts menu and prints per-bin counts from `~/Library/Logs/wellset-resolve-import.log`. Re-runnable. Client footage lives at `/Volumes/Extreme SSD/wellsetmedia/clients/<name>/03 media/`. First used 2026-10-02: Kyle Ritchie `seminar`, 1,082 clips, 0 failed. Flags added 2026-10-07: `--project "Name"` creates and opens a new project first, with the frame rate set from the footage (Resolve locks it once a timeline exists), and `--skip "<subfolder>"` leaves a folder out. Lua arrays aside, his shell is **zsh, where arrays are 1-indexed**: this bit me renaming the ATEM studio-day takes.

**"Audio only in my left ear" fix:** his A7 (`A74xxxx.MP4`) clips shot with the external mic record on channel 1 only (channel 2 sits at ~-85 dB); the `C7xxx` clips are fine. Find them with an ffmpeg `astats` per-channel RMS scan, don't trust "all the videos". The API can read audio mapping (`GetAudioMapping`, `GetSourceAudioChannelMapping`) but **cannot set it** — it's Clip Attributes > Audio via computer use: keep Format **Stereo** and set BOTH Source Channel rows to Embedded Channel 1. **Do NOT set Format Mono** — a mono clip on his stereo tracks still plays left-only (got this wrong 2026-10-02). His dual-mic kit puts one mic per channel, so check full-length levels on channel 2 before discarding it. **Pool Clip Attributes do NOT reach clips already on a timeline** — marquee the timeline clips and do Clip Attributes there too. Verify with the mapping getters. `mp:SetCurrentFolder` + `mp:SetSelectedClip` navigate the pool without touching the tiny bin tree. He keeps editing in Resolve while Claude works (mouse, trim mode, playback, moving the window between the built-in and the Dell) — computer use collides with his hand, drags land in the wrong place. Ask for hands-off BEFORE starting any mouse work in Resolve, and re-probe the timeline after any collision.

Gotchas: a bin containing timelines/compound/Fusion clips makes Resolve reject the whole Power Bin drag ("Power Bin Not Updated") — the MotionText `.drb` carries timelines, so keep it out. Accented filenames on the exFAT SSD are NFD and Resolve refuses them — pass NFC paths. Import stills one per call or numbered PNGs collapse into an image sequence. New scripts take a few seconds to appear in the Scripts menu — poll the menu before clicking. He swipes Spaces while working, so screenshots can land mid-transition.
