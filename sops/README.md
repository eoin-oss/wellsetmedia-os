# WellSetMedia SOPs

Rebuilt 28 Oct 2026 from the first full month run end to end. One page each: trigger, steps, done when, rules.
Client-specific rules never live here. They live in `clients/<slug>/CONTENT-RULES.md`
(template: `clients/_template/CONTENT-RULES.md`).

```
01 leads + audit → 02 sales call → 03 onboarding → 03b research → 04 pre-production → 05 shoot
      → 06 edit → 07 QC → 08 approval → 09 scheduling → 10 month end → back to 03b
```

| # | SOP | One line |
|---|---|---|
| 01 | [Leads + audit](./01-leads-and-audit.md) | ICP check first, then the full audit |
| 02 | [Sales call](./02-sales-call.md) | Prep, call, custom plan, book onboarding on the close |
| 03 | [Onboarding](./03-onboarding.md) | Payment, questionnaire, client rules file (being rebuilt as a client hub) |
| 03b | [Research + iteration](./03b-research.md) | Keywords, 500k+ outliers, grow/nurture/sell, why it worked. Month 1 tests, then repeat winners + test new |
| 04 | [Pre-production](./04-pre-production.md) | Scripts written and reviewed by the deadline |
| 05 | [Shoot](./05-shoot.md) | Date never moves. Day-before check, b-roll block, footage handled same day |
| 06 | [Edit](./06-edit.md) | Rules in before the build, pilot 3, then the batch |
| 07 | [QC](./07-qc.md) | Cold eyes, at least 1 hour after the edit. Machine checks + phone watch |
| 08 | [Approval](./08-approval.md) | Nothing posts without an explicit approval |
| 09 | [Scheduling](./09-scheduling.md) | Approved + PASS only. Blotato |
| 10 | [Month end](./10-month-end.md) | Report + call in the last week, then the internal retro |
