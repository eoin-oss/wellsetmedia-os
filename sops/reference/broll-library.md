# SOP 06 — the b-roll library

One library, every usable shot findable in seconds. Feeds Eoin's reels first, client work second.

## Structure (create at the footage drive root)
```
B-ROLL/
  craft/        cameras, lights, edit bay, on-set mechanics
  founder-life/ eoin working: calls, planning, travel, gym
  client-sets/  pulled from client shoots — PORTFOLIO-USE RULES APPLY
  texture/      coffee, streets, golden hour, atmosphere
  _inbox/       everything unsorted lands here first
  catalog.csv
```

## catalog.csv — one row per kept clip
`file,category,tags,length_s,orientation,graded,source,rights,date`
Rights column is the one that matters: `own` / `client-portfolio-ok` / `needs-release`.
Nothing from client-sets gets used until its row says client-portfolio-ok.

## Rules
- Clips are 5–30s, one idea each. Long takes get split.
- Vertical native beats cropped, but a 4K horizontal crops to vertical fine — tag orientation.
- client-sets audio: never use audio from a client set (confidentiality clause). Visual only.
- Every shoot (client or personal) owes the library 5 clips minimum. Tax on every shoot day.
- Graded clips only in category folders; ungraded stays in _inbox.

## The sorting task (send this to the editor — the bonus job)
> Going through the client footage folders I share. For each: pull every shot that works as
> standalone b-roll (5–30 seconds, one clear action or image, no client-sensitive screens or
> paperwork visible). Crop or export vertical 4K where it works. Grade to the reference clips.
> File into the category folders above, add a row per clip to catalog.csv with tags (3–5 plain
> words each, e.g. "gimbal, walking, night"). Leave rights column blank — Eoin fills it.
> Priority: shots of Eoin working, camera mechanics, and anything cinematic from sets.

Eoin's pass afterwards: fill rights per clip. Ten minutes. Nothing publishes before that.
