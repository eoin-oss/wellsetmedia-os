# Story sequences (locked 12 Nov 2026)

IG story sequences for Eoin and every client, built on a live page the person edits with us, then exported as
final 1080x1920 JPGs. Run it with the `/story-sequence` skill (`~/.claude/skills/story-sequence/SKILL.md`).

**Trigger:** a story is in the month plan (04), or Eoin wants one for himself.

## Steps
1. Phone snaps into one folder. `prep.py` sorts them into images/videos and makes the full-res + web copies.
2. Beats drafted, each on a photo. The person approves the words (08 for clients).
3. The edit page goes live (photos + the saved draft). Share the link with the client from the page's Share menu.
4. They edit on the page or tell us. It autosaves, we read it back.
5. On their go: export, check the contact sheet, send the folder (AirDrop for Eoin, Frame for clients).

**Done when:** the approved frames are exported and in the client's hands or scheduled (09).

## Structure (added 12 Nov)
- One type per sequence: documentation, wins, value, limiting belief.
- Hook (frame 1) -> amplifier (frame 2 or 3) -> value -> CTA only when it's the CTA slot. Full lists in the skill.
- 3 a week: Mon documentation (no CTA), Wed free value drop (keyword to get it), Fri wins or belief (offer keyword).
- Proof only from the proof bank (`content/proof-bank/` for Eoin, `clients/<slug>/proof-bank/`).
- After posting, log type, hook, amplifier, replies and per-frame drop-off in the job's `results.md`.
- Clients: they drop the week's phone snaps by Friday; we draft the 3, they approve on the page.

## Rules
- Scarcity only if real. Controversial = against an idea, never a creative. No unknown names. Real sources only.
- Locked look: real photo per frame, black boxes, white bold text, red for pain, one accent box per frame,
  `...` on every frame but the last, CTA keyword on the last. Accent: Eoin white, Kyle gold, others per brand.
- Text inside the IG safe area, never on a face. No em dashes, no price, no invented proof.
- Other people in a photo: get their OK before it posts.
- First run: Eoin's "weekend into a month of content", `content/stories/weekend-story/`.
