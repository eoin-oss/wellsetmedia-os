# 05 · Shoot

**Trigger:** the day before a shoot. In person only. No remote offers for now.

## Steps
1. **Day before:** scripts locked (04), shot list by setup, kit packed and charged, cards formatted,
   call sheet sent 48h out (template: `_archive-2026-10/02-shoot-day.md`).
2. Interview set lit and sound checked first.
3. Shoot by setup, not by script.
4. **B-roll block every shoot**, for the client's library: hands, work, movement, environments, emotions the scripts need.
5. Same day: offload, back up to two drives, label the folders.
6. **Log the picture profile** for every clip (S-Log or not) so the edit never guesses the grade.
7. Mark selects the same night.

**Done when:** footage is backed up twice, labelled, profiles logged and selects marked, on the day.

## Rules
- The shoot date never moves.
- One free client reschedule a month with 48h notice. Inside 48h it counts as the shoot.
- Remote self-shoot only as an agreed exception, with a written brief. It is not the standard.
